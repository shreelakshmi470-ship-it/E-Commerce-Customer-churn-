- Created databases and tables to manage customer data.
- Performed data cleaning and preprocessing, including handling missing values and standardising data.
- Used SQL queries, aggregate functions, GROUP BY, CASE statements and subqueries for analysis.
- Analysed customer churn, complaints, tenure, payment preferences, coupon usage, cashback and order patterns.
- Derived business insights to understand customer behaviour and support better retention strategies.
